### [Click to play 3D Maze](/3d-maze)

Steam's new standalone VR headset, the [Steam Frame](https://store.steampowered.com/hardware/steamframe), is set to release very soon! To celebrate, I thought it would be fun to enable 3D Maze to work with Virtual Reality. This update adds support for all VR headsets through a compatible web browser. This means Quests, PCs with headsets attached, and even Android phones with Google Cardboard can now play in VR. When you load the game in a compatible browser, you'll see an 'Enter VR' button like the one shown below. Since this is always available on Android phones, you can enter VR through the options menu.

![3D Maze Menu with VR enabled](/images/postmedia/3dmaze_vr_button.webp)

## Additional Changes
This feature forced me to rework several things I'd been avoiding for years, the biggest of which is the menu system. This should more easily enable additional features like modes or different maze generation options in the future.

Other changes:
- Fixed offline webapps
- Since November 2025, rendering of particle effects is much more efficient than the original release

## Looking Forward
After immersively getting lost in some larger mazes, it really feels like you should be able to leave yourself hints near dead ends... Expect something in the coming months (VR + normal gameplay)
